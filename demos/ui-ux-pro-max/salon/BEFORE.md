# Before — generic salon template (baseline)

Single-file starting point copied from the classic generic salon layout:
Playfair Display + Inter, hero with overlay claim, 6 service cards,
about split, 3-image gallery, 3 price cards, contact info + booking form.

No design system applied: raw hex in components, placeholder-only
patterns avoided but helper text, focus rings and submit feedback are
missing — those gaps are what the UI/UX Pro Max pass fixes in `after.html`.
